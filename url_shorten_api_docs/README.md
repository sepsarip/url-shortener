# URL Shortener API Documentation

This folder contains the API documentation for the URL Shortener service using [Bruno](https://www.usebruno.com/) API client format.

## What is Bruno?

Bruno is a fast, git-friendly, offline-first API client. Unlike Postman or Insomnia, Bruno stores collections directly in your filesystem using plain text files, making them perfect for version control.

## Setup

1. **Install and download Bruno**
   - Download from [usebruno.com](https://www.usebruno.com/downloads)

2. **Open Collection**
   - Launch Bruno
   - Click "Open Collection"
   - Select this folder (`url_shorten_api_docs`)

3. **Configure Environment**
   - Set the `BASE_URL` variable:
     - Local: `http://localhost:3000`
     - Production: `https://your-domain.com`

\*for more information visit [bruno docs](https://docs.usebruno.com/introduction/what-is-bruno)
